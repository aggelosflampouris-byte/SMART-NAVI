# SMART-NAVI Project

Welcome to the main repository for the SMART-NAVI application. This document provides a high-level overview of the project and how to get started.

## Project Structure

This project is a monorepo containing the following components:

*   `frontend/`: The user interface built with React and Vite.
*   `backend/`: The API server built with Python and FastAPI.

## Getting Started

Each part of the project has its own setup instructions located within its respective directory.

### Frontend Setup

To run the frontend application, you will need to navigate into the `frontend` directory and follow the instructions in its dedicated `README.md` file.

For your convenience, here is a quick start guide:

```bash
# Navigate to the frontend directory
cd frontend

# Install dependencies
npm install

# Run the development server
npm run dev
```

For more details on prerequisites and available commands, please see the frontend/README.md file.
